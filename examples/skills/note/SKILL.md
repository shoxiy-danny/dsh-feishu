# Note

随手记，不是长期记忆，也不是定时器。拷到 dsh 会扫的 skills 目录，例如 `~/.dsh/skills/note/`。

文件：`~/notes.md`（家目录，不跟项目走）。没有就建。

## 触发

记录：「记一下」「别忘了」「记着」「帮我记一下」
查询：「查一下笔记」「我之前记了什么」「我有没有记过」「翻一下笔记」

不触发：

- 「记住 / 忘掉」→ 全局记忆（`DSH_FEISHU_MEMORY_DIR`），不是本文件
- 「看看这个 / 帮我看一下」+ 链接 → 当场读，不入库
- 「提醒我」→ 不在本 skill。本插件没有内置 cron，不要写进笔记假装会响，也不要擅自装定时器

拿不准类型先问再写。不要脑补内容。

## 格式

按日分节，同一天归入同一 `##`：

```
## YYYY-MM-DD

- HH:mm [类型] 内容
```

涉及今天必须先 `date`，不能编。时间用本机本地时区。

| 类型 | 何时 | 例子 |
|------|------|------|
| `[备忘]` | 电话、地址、账号、事实 | 王总电话 138xxxx |
| `[待办]` | 要做、无固定时刻 | `[待办] 【项目名】 补 INDEX` |
| `[想法]` | 灵感 | 可以做自动日报 |
| `[日程]` | 有具体时间的安排 | 下周二 15:00 开会 |
| `[链接]` | 以后再看的 URL | 用户明确说「记一下」的链接 |
| `[完成]` | 只由 bye 从 `[待办]` 改过来 | 不要手写这一类当新记 |

`[待办]` 能归到项目就加 `【项目名】`，bye 对账才对得上。随手琐事可以不加。

一行一事。不要把长文、聊天记录、报告塞进来。

## 查询

- 「查一下笔记」→ 读全文，原样回，不要摘要、不要挑着说
- 「查一下关于 XXX」→ grep `~/notes.md`，命中行连同所在日期节一起回
- 文件不存在 → 说还没有笔记，不要建空文件（除非用户正在记）

## 和另外两层的边界

| 东西 | 文件 | 谁写 |
|------|------|------|
| 随手记 / 待办清单 | `~/notes.md` | 本 skill；bye 只改 `[待办]`↔`[完成]` |
| 长期偏好 / 铁律 / 进行中的项目状态 | `$DSH_FEISHU_MEMORY_DIR` 分文件 | 记忆规则；禁止写进 notes.md |
| 这次会话干了什么 | `<项目>/logs/…` | checkpoint / bye 摘要；禁止写进 notes.md |

## 铁律

- 先确认用户要记的原文，再追加。禁止改写意思
- 只追加，不改旧行（完成态交给 bye）
- 查询回完整命中，不总结
